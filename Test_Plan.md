# Test Plan – ParaBank

## 1. Objective

Validate the functional behavior, navigation, input validation, transaction workflows, and basic usability of the ParaBank demo banking application.

## 2. Test Types

- Functional testing
- Smoke testing
- Sanity testing
- Regression testing
- Negative testing
- Boundary value testing
- Input validation
- UI/navigation testing
- Basic compatibility checks
- Basic API/service mapping

## 3. In Scope

Customer-facing banking workflows and supporting pages exposed by the public demo application.

## 4. Out of Scope

- Real financial transactions
- Production banking security certification
- Performance/load testing against the public demo server
- Destructive security testing
- Infrastructure penetration testing
- Real customer data

## 5. Entry Criteria

- Application URL accessible
- Test data available
- Browser available
- Test cases reviewed

## 6. Exit Criteria

- Planned test cases executed
- Critical defects documented
- Regression completed for fixed defects
- Test summary prepared

## 7. Test Environment

- OS: Windows 10
- Browser: Google Chrome
- Application: ParaBank public demo
- Execution date: 2026-09-11

## 8. Risk

The public demo database may be reset periodically. Test accounts and balances should therefore be treated as disposable.
